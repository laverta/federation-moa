# Data Cleansing · Z 轴负熵海关 (孵化中规范 · RFC)

> **开源诚实声明**：本技能当前处于**架构规范与测试孵化阶段 (Incubating)**。在当前三剑客开源版本中，数据清洗与技能路由逻辑以内联中间件形式运行于 `moa-engine/` 与 `dsh-core/dsh_advisor.py` 中。本目录作为独立技能抽取规范存证，供社区演进与二期拔高。

## 一、 核心职责定义

1. **入口生肉去噪 (Raw Input Normalization)**：
   - 过滤用户提示词中的情绪噪声、冗余客套与模糊指代；
   - 提取结构化工程目标与硬性语法断言约束。
2. **联邦宝库分级装配 (Vault Dispatcher)**：
   - 检索 `skills/vault_index.json` 中的 30 项高星技能元数据；
   - 执行三级漏斗匹配：领域初筛 -> 评分加权 -> 任务卡精准配装。
3. **上下文防爆仓约束 (Anti-Context Bloat)**：
   - 单任务单次只允许动态挂载 1~3 个技能上下文，严禁全量盲目加载；
   - 严格压制 Token 消耗，防止 Flash 模型因超长注意力衰退出现幻觉。
4. **越俎代庖病理拦截 (Anti-Overstepping)**：
   - 监测并拦截“规划席擅自写最终代码”、“施工席擅自变更架构规范”等组织协作违宪行为。
