## 第一讲：单写并发——为什么"只有一个写者"能消灭一整类 bug

**问题**：Windows 有强制文件锁（WinError 32）；两个进程同时改一个状态文件 = 后写者胜 = 静默丢数据（FM-05/08）。

**方法论三层**：
1. **职责单写**：每个文件有且只有一个写者进程（DSH 只读 INBOX.ndjson、只追加 OUTBOX.ndjson；绝不直写他席存储）。人看的投影（.md）与机器队列（.ndjson）分离——机器永不解析给人看的文件（FM-11 修正案）。
2. **原子写三步**：`.tmp` 写入 → `flush()+fsync()` → `os.replace()`。断电/崩溃任意时刻，文件要么旧要么新，永无半态。
3. **实例排他**：单写者的前提是单实例——PID 锁（启动前 os.kill(pid,0) 探测旧实例，存活即 REFUSE 退出，DSH 实测退出码 3）。没有第 3 层，前两层会被"两个合法写者"绕过。

**反例实证**：STATUS.md 是多写者文件，运行 48h 已发生两次并发覆盖冲突，靠"写前必读+冲突重读合并"人肉兜底——能用纪律兜底的都算幸运，设计目标是让幸运不必要。

## 第二讲：状态持久化——At-least-once 与 WAL 顺序契约

**问题**：跨多个文件的状态（产出 OUTBOX + 游标 cursor + 状态 state）没有事务，崩溃窗口内"信处理了但游标没推"= 重启后重复执行（FM-10）。

**方法论**：
1. **顺序契约**：永远**先落盘外部产出（追加+fsync）→ 后推内部游标（原子替换）**。崩溃在中间？重启重读重执行——重复不可怕，丢失才可怕（At-least-once 哲学）。
2. **幂等去重**：重复执行要不产生副作用——复合去重键 `task_id#msg_type#seq`（ARCH v1.1）。注意必须是**复合键**：单用 task_id 会误吞同一工单生命周期里 TASK/WORKING/RESULT 多种信型（FED-CORE 实战教训）。
3. **游标版本化**：游标推进用版本序列号，先落盘后使用（WAL 语义，重启不重号）。
4. **有界账本**：committed_keys 只留最近 N 条（DSH 取 500），防无限膨胀。

**验证手法**：selftest 里必含"重复 Tick 零副作用"断言——幂等性不是写出来的，是测出来的（dsh_runtime selftest 实证：第二次 process_once processed=0、OUTBOX 行数不增）。

## 第三讲：容灾降级——会话必死，进程永生

**第一性原理**（48h 五案复盘提炼）：**凡依赖"会话活着"的机制都会死；凡落在文件与进程上的零 token 机制都活了。**

**方法论**：
1. **动静分离**：探测/等待/心跳 = 0 token 常驻进程（os.stat 轮询）；思考/执行 = 模型事件驱动单次唤醒。谁混用谁死（子 agent 站岗 46 秒撞配额案）。
2. **活性四元组**：`{pid, mtime, lease_expires_at, last_seq}`——进程在≠健康：租约 TTL（600s）超时或游标不推进 = 僵尸假死，强制回收（FM-09）。判活要判"进展"而非"存在"。
3. **自愈的终止点**：看门狗拉起进程，谁看护看门狗？递归终止于 OS 计划任务（5min 自愈）。且拉起必须带指数退避+崩溃计数（30s→60s→120s→CRASH_DUMP 强制暂停），否则秒崩秒拉烧 CPU。
4. **池级熔断**：单工单步长配额（MaxStep=15）防死循环；连续 2 次配额类报错即判**池枯竭**→ 全局 TRIPPED → 降级 DEGRADED_FILE_ONLY（只转发文件+心跳，不唤醒模型）→ 桥上通报 → 等重置窗口自动复位（FM-12）。降级是能力，不是失败。
5. **编码宪法**：Windows 下中文 = 显式 `encoding="utf-8"` 处处声明 + 入口 reconfigure。这不是风格，是上线与炸机的一线之隔（FM-07，FED-CORE 实测第一炸点）。

## 三讲合璧：一张验收表

| 契约 | 检验断言（靶场化） |
|---|---|
| 原子写 | kill -9 后无半态文件；残留 .tmp 被安全清理 |
| 单实例 | 双开第二实例 REFUSE（exit 3） |
| At-least-once | 重复投递同 seq 信 → processed=0，OUTBOX 不增 |
| 信封 | canonical 字节级复现；篡改 payload → checksum 拒绝 |
| 租约 | 停刷 mtime 600s 后读者判失效（无需善后） |
| 降级 | 模拟 quota 报错 ×2 → 状态机进 DEGRADED_FILE_ONLY |

**一句话毕业**：把每一次"应该不会崩"变成一个靶场断言——**不可复现的严谨都是玄学**（指挥官语）。
