# 📊 Federation-MOA 评测全景白皮书 (Empirical Benchmark Ledger)

> **核心结论**：在 BigCodeBench-Hard (40 题全量盲测黄金用例) 严苛评测中，由轻量级三剑客（DeepSeek v4.1 Flash、Gemini 3.8 Flash、GLM 5.3 Flash）组成的多智能体协同系统，通过 **前向 3 阶段解耦** 与 **测试时算力膨胀 (Test-Time Compute · TTC)**，取得了 **Pass@2 57.5%** 的优异战绩，越级超越单体闭源旗舰模型（42.6% ~ 45.0%），且单任务 Token 开销与调用成本仅为旗舰模型的 1/10。

## 二、 突破 Flash 模型长程缺陷机制：测试时算力膨胀 (TTC)

传统 Flash 模型受限于浅层注意力和快速解码策略，长任务中存在“贪婪冲动”与“错误级联”两大死穴。Federation-MOA 提出了**系统级时空膨胀架构 (System-Level Test-Time Compute)**：

```
       [人类指挥官输入宏观目标]
                  │
                  ▼
┌────────────────────────────────────────────────────────┐
│ 【阶段 1: 宏观收敛与无状态 DAG 切片】 (~3,500 Tokens) │
│  - 执政席位: Gemini 3.8 Flash (1M 视界)                 │
│  - 输出: 3~5 张上下文隔离的 DAG 任务卡 (<6K Tok/张)   │
└─────────────────────────┬──────────────────────────────┘
                          │
                          ▼
┌────────────────────────────────────────────────────────┐
│ 【阶段 2: 逆向红队挑刺与军需配装】     (~6,500 Tokens) │
│  - 执政席位: DeepSeek v4.1 Flash (T-1 鉴别器)          │
│  - 输出: 挖掘 3 大死穴，从 vault_index 调配 1~3 件技能 │
└─────────────────────────┬──────────────────────────────┘
                          │
                          ▼
┌────────────────────────────────────────────────────────┐
│ 【阶段 3: 带装施工与本地 AST 语法自愈】 (~15,000 Tokens)│
│  - 执政席位: GLM 5.3 Flash / Builder                   │
│  - 机制: 本地 AST 语法解析 + 断言夹具，多轮自愈闭环   │
└─────────────────────────┬──────────────────────────────┘
                          │
                          ▼
┌────────────────────────────────────────────────────────┐
│ 【阶段 4: 结晶断面与 SHA-256 签名终审】                │
│  - 产物: Unified Diff 结晶，座舱 1-Click APPROVE 裁决  │
└────────────────────────────────────────────────────────┘
```
