## 分歧条款（呈指挥官裁决）

### D1 装备官模型（实质分歧）
- 我方：**GLM 5.3 Flash**——与 Builder 同族格式天然对齐；走 DSH 工单通道零部署（适配器已上线）；
- 对方：**DeepSeek v4.1 Flash**——"冷酷审计"人设贴合；BCB 实证能精准锁定隐蔽陷阱；国内直连极稳、成本极微（¥0.001/千字）。
- 统筹意见：**采对方（DeepSeek）**——装备官的核心价值是"挑刺式对比"，独立性比同族对齐更重要（装备官与 Builder 同族有"自查自批"之嫌，违背验收独立性原则）；且 DeepSeek 的 BCB 37.8% 是挑错能力的实证。GLM 5.3 Flash 作为热备。

### D2 装备清单深度
- 我方：轻量四件套（skill/source/mount/usage+why）；
- 对方：重装七件套（+version/gold_standard_snippet 金样代码/red_lines 红线/verification_harness 验收断言）。
- 统筹意见：**采对方重装版为标准**，但分级适用——关键流（涉协议/安全）必须带金样+红线+harness；机械流（如 cmd 替换）允许轻量四件套（防过度工程，Ponytail 阶梯）。

### D3 L2 匹配算法实现

- 对方：BM25 词法 + Embedding 余弦，阈值 0.75 命中 / <0.70 触发 L3。
